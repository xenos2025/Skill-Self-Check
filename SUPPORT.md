# Support

## How to get help

1. Read [docs/INSTALLATION.md](docs/INSTALLATION.md) and [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Search existing GitHub Issues.
3. Open a new issue with:
   - OS and Python version (`python --version`)
   - Install path (`~/.cursor/skills` vs project)
   - Command run and JSON / stderr from `hard_gates.py` (redact secrets)

## What we can help with

- Installing and running `skill-self-check`
- Interpreting `basic_usable` / `contract_clarity` scores
- Bugs in `hard_gates.py` or checklist mismatches

## What we cannot commit to

- Free consulting to design your company's full ops stack
- Guaranteed review of every skill you publish
- Hosting or SaaS SLA (this is an open-source skill pack)

Product / PM workflow experiments live under [`exp/`](exp/README.md) and may
change without the same stability guarantees as `skills/`.
