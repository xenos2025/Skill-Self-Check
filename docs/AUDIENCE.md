# Audience

## Who this is for (today)

| Audience | Why |
| --- | --- |
| Skill authors (Cursor / Claude Code / Codex) | Self-check a new `SKILL.md` before sharing |
| Small teams packaging internal skills | Same hard gates for everyone |
| Open-source skill maintainers | Scripted scores in PR review |

## Who this is not for (today)

- End merchants who never write skills
- Teams needing a hosted SaaS skill marketplace
- Fully automated behavioral eval grids (roadmap)

## Who the `exp/` hook is for (next)

Product / ops people helping **foreign trade, factory, and ecommerce** teams:

- Map messy work into an agent workflow
- Propose which skills to build or buy
- Keep proposals productized (acceptance, evidence, ship floor) — not slideware

Stable install path remains `skills/`. Growth experiments stay in `exp/` until
promoted.
