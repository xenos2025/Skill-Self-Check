# Privacy

This package runs **locally**. The hard-gate script does not phone home.

## Data the skill may touch

- Paths and contents of Agent Skills you ask it to review (`SKILL.md` and
  sibling files)
- Optional chat context when an agent runs the qualitative passes

## What not to put in this repo

- API tokens, `.env` files, Shopify/Admin credentials
- Customer PII, inquiry exports, or factory order sheets
- Filled client configs under `exp/` in a public fork

## Experiments (`exp/`)

Future PM workflow demos may describe processes for foreign trade, factories,
or ecommerce. Treat those as **methodology drafts**. Keep real business data
in a private workspace outside the public tree.
